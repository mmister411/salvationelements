# VITAL Compendium

VITAL Compendium contains seven operations, the VITAL Harness, and Substrative Commitments.

## Example invocations

- “Use VITAL Survey on this passage.”
- “Create VITAL DAUs on grace and judgment.”
- “Use VITAL Author from this seed: …”
- “Strike the Anvil: nominate revision candidates from this essay.”
- “Use Explorative Explicator on this argument.”
- “COLLAPSE this proposal.”
- “DECOMPOSE this concept.”

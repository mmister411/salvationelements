# Competency Questions

The ontology and graph should support direct answers to these questions without changing the meaning of the authored predicates.

1. Which current graph nodes have admitted substrate statements in the Substrate Statement Corpus, and which graph nodes do not?

2. What authored relations leave a given node, and what authored relations terminate at it?

3. What distinct authored paths connect Adultery to Sin?

4. What distinct authored paths connect Adultery to Breach?

5. Through which authored path is Adultery related to Treachery, Malice, and Idolatry?

6. Which nodes are authored as `FormOf` Sin?

7. Which nodes are authored as `FormOf` Breach, and which additional nodes would become forms of Breach only if a particular `FormOf` composition rule were authorized?

8. Where do multiple independent paths converge on the same node or relation family?

9. Which nodes directly `Implies` God, and what longer authored paths reach God through one or more `Implies` edges?

10. Which bidirectional `Implies` relationships are explicitly authored as two directions, without assuming that `Implies` is globally symmetric?

11. Which nodes directly `Requires` Will, Assent, Commitment, Logic, or God?

12. What authored paths show Sin bearing upon Will, Affinity, Agape, Personhood, Logic, Assent, Holiness, and Breach?

13. Which relations concerning a node express categorical participation through `FormOf`, which express co-operation through `Instantiates`, and which express warrant through `Implies`?

14. Can a proposed derived edge be traced to an explicit candidate inference rule and to every authored edge on which it depends?

15. Which candidate inferences fail if `FormOf` is not transitive in the applicable sense?

16. Which graph paths are structural discoveries only and therefore must not be presented as logical entailments?

17. Which proposed edges require an applicability condition before they can be represented without overstatement?

18. Does adding a new graph node change only graph membership, or is there independent evidence that the term has received an admitted substrate statement?

19. Can a graph query distinguish a node becoming structurally prominent from that node becoming a substrate?

20. When two paths reach the same conclusion, do they preserve different warrants that should remain recoverable rather than being collapsed into a single unexplained edge?
